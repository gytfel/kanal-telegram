# Автопостинг в Telegram-канал

Бот сам выбирает рубрику, придумывает тему, пишет пост и публикует его в канал по расписанию. Твоё участие — только настроить один раз.

Что внутри:
- ротация рубрик — канал не превращается в одну и ту же статью по кругу;
- память прошлых тем: новые посты сверяются со старыми, повтор отправляется на перегенерацию;
- случайный сдвиг времени публикации ±8 минут, чтобы не выглядело автоматом;
- повторы при сбоях сети, обработка флуд-контроля Telegram, лог в `bot.log`.

---

## Шаг 1. Установка

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
```

## Шаг 2. Три ключа

Скопируй `.env.example` в `.env` и заполни:

**TELEGRAM_TOKEN** — напиши [@BotFather](https://t.me/BotFather), команда `/newbot`, придумай имя. В ответ придёт строка вида `1234567890:AAE...` — это токен.

**CHANNEL_ID** — создай канал и добавь своего бота в администраторы с правом «Публикация сообщений» (без этого он не сможет постить).
Само значение можно вставлять как удобно — бот разберёт:

- публичный канал → `@imya_kanala`, или просто ссылка `https://t.me/imya_kanala`, или ссылка на любой пост `https://t.me/imya_kanala/123`
- приватный канал → открой любой пост в канале, «Копировать ссылку», получится `https://t.me/c/1234567890/56` — вставляй её целиком
- числовой id `-1001234567890`, если он у тебя уже есть, тоже подойдёт

Единственное, что **не** сработает, — ссылка-приглашение вида `https://t.me/+AbCdEf...`: Telegram не даёт ботам определить по ней канал. Для приватного канала бери ссылку на пост, как описано выше.

**ANTHROPIC_API_KEY** — зайди на [platform.claude.com](https://platform.claude.com), раздел Settings → API keys, кнопка Create key. Ключ показывается один раз, сразу скопируй. Нужен привязанный способ оплаты.

## Шаг 3. Настрой канал под себя

Открой `config.py` и поменяй блок «О ЧЁМ КАНАЛ»: `CHANNEL_TOPIC`, `AUDIENCE`, `TONE`, `RUBRICS`. Чем конкретнее опишешь — тем лучше посты. Плохо: «про бизнес». Хорошо: «маркетплейсы для селлеров-новичков: логистика, карточки, юнит-экономика».

Там же — время публикаций в `POST_TIMES` и часовой пояс.

## Шаг 4. Проверка и запуск

```bash
python bot.py --check     # три ключа + права бота на публикацию в канале
python bot.py --dry-run   # показать пост в консоли, никуда не отправляя
python bot.py --now       # опубликовать один пост прямо сейчас
python bot.py             # рабочий режим: постит по расписанию
```

Сначала прогони `--dry-run` раз пять и покрути формулировки в `TONE`, пока тексты не начнут нравиться. Это единственное, на что стоит потратить время.

## Как оставить работать 24/7

Скрипт постит, только пока запущен. На домашнем ноутбуке он умрёт вместе с крышкой — нужен сервер (подойдёт самая дешёвая VPS).

**Установка на VPS одной командой.** Подключись к серверу по SSH и выполни:

```bash
sudo apt update && sudo apt install -y python3 python3-venv git
git clone https://github.com/gytfel/kanal-telegram.git
cd kanal-telegram
./install.sh
```

`install.sh` сделает всё сам: проверит версию Python, создаст виртуальное окружение, поставит зависимости, спросит три ключа и запишет их в `.env` с правами 600, прогонит `--check` и предложит поставить автозапуск через systemd. Скрипт идемпотентный — можно запускать повторно, уже сделанное он не трогает.

Не забудь **до** запуска добавить бота администратором канала с правом «Публикация сообщений»: `--check` внутри установщика это проверяет и не даст поставить сервис, который всё равно не сможет постить.

Управление после установки:

```bash
sudo systemctl status tgbot      # состояние
sudo journalctl -u tgbot -f      # живой лог
sudo systemctl restart tgbot     # перечитать config.py после правок
sudo systemctl stop tgbot        # остановить
```

Поднимется сам после перезагрузки сервера и после любого падения.

Флаги на случай неинтерактивной установки: `./install.sh --service` — поставить сервис молча, `./install.sh --no-service` — только окружение и ключи.

**Docker** — если привычнее:

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["python", "bot.py"]
```

```bash
docker build -t tgbot . && docker run -d --restart=always --env-file .env tgbot
```

## Сколько стоит

Один пост — примерно 1500–2500 токенов. При трёх постах в день это единицы долларов в месяц на `claude-sonnet-5`. Хочешь дешевле — поставь в `config.py` `MODEL = "claude-haiku-4-5-20251001"`, умнее и дороже — `claude-opus-5`.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| `chat not found` | бот не добавлен в канал админом, или неверный `CHANNEL_ID` |
| `not enough rights` | у бота в админке нет права «Публикация сообщений» (ловится `--check`) |
| `invalid x-api-key` | ключ Anthropic скопирован с пробелом или отозван |
| `credit balance is too low` | не привязана карта в консоли |
| посты повторяются | расширь `RUBRICS` и подробнее опиши `CHANNEL_TOPIC` |
| посты пресные | правь `TONE` — это влияет сильнее всего |

Все ошибки пишутся в `bot.log` рядом со скриптом.

## Важное про автономность

Полностью без присмотра модель может выдать фактическую неточность — она не проверяет факты в интернете. Поэтому в промпте стоит запрет на выдуманные цифры, даты и цитаты, а рубрики сделаны «вечнозелёными», без привязки к новостям. Если захочешь новостной канал — туда нужно подключать поиск и это уже другая конструкция, скажи, соберу.

Раз в неделю всё же пролистай, что там вышло: 5 минут, и ты в курсе, чем живёт твой канал.
